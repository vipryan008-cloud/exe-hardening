# 要防的对象：Windows 脱壳 / 逆向工具与对抗点

（知己知彼。此表指导各层设计——每个工具对应我们哪一层挡它。）

## 静态分析
| 工具 | 能力 | 我们挡它的层 |
|---|---|---|
| IDA Pro / Ghidra | 反汇编、反编译、交叉引用 | **L1**（代码段密文）+ **L3**（虚拟化后无 x86） |
| PE-bear / CFF Explorer | 看段表/导入表/资源/熵 | L1 只加密 .text（熵会升，属预期）；抹 IAT 见 L1 路线 |
| strings / FLOSS | 抓明文/去混淆字符串 | 敏感串加密（.rdata 层，L1 路线扩展） |
| DIE (Detect It Easy) | 识别壳/编译器特征 | stub 变形 + 去特征（L1 路线 §6） |

## 动态脱壳 / dump
| 工具 | 能力 | 我们挡它的层 |
|---|---|---|
| x64dbg + Scylla | 跑到 OEP → dump 内存 → 重建导入 | **L2**（函数默认不在内存）+ 抗dump（抹头） |
| Frida | 注入 hook、跟踪 API、内存转储 | **运行时对抗**（PEB/timing 检出）+ maps/端口检测 |
| PE-sieve / Moneta | 扫进程内存找被改/无模块支撑的代码 | L2 惰性回填减少常驻明文；stub 段合法化 |
| ScyllaHide | 反-反调试插件，隐藏调试器 | 多路交叉检测（PEB 直读 + 硬件断点 + timing 难全绕） |

## 调试 / 分析环境
| 工具 | 能力 | 我们挡它的层 |
|---|---|---|
| WinDbg / x64dbg | 断点、单步、改内存 | 运行时：硬件断点/单步 timing/NtGlobalFlag |
| 沙箱 (Cuckoo/云沙箱) | 自动化行为分析 | 反VM（CPUID hv 位/vendor 串） |
| Windows 内核调试 | 更底层 | 出 L1/L2 范围；商用壳亦有限，靠运行时 + 法务边界 |

## 对抗点清单（我们必须做到的）
1. 静态看不到原码 → **L1 已达**（.text 密文 + 反汇编垃圾）。
2. 跑到 OEP dump 拿不到完整代码 → **L2**（惰性回填）+ 抗dump（抹头）。
3. 关键函数无原生指令可分析 → **L3**（虚拟化）。
4. 调试器/VM 一挂就检出并处置 → **运行时对抗 已达**。
5. 篡改（改校验、爆破）即失效 → 运行时自 CRC + 签名（Authenticode）+ L3 校验虚拟化。
